# KAAFI HSSE Platform - Project Definition

## Project Goal

KAAFI HSSE Platform is a fresh MVP system for industrial Health, Safety, Security, and Environment workflows.

The MVP focuses only on:

1. Job Safety Analysis (JSA)
2. Risk Assessment
3. Permit to Work (PTW)
4. Simple Dashboard
5. Basic AI Safety Assistant using rules first

## Build Order

1. Initialize clean project structure
2. Build simple user authentication
3. Build JSA module
4. Add Risk Assessment
5. Add Permit to Work
6. Add Dashboard
7. Add basic rule-based AI assistant

## MVP Principles

- Build simple first.
- Keep modules clean and isolated.
- Avoid enterprise complexity until needed.
- Use rule-based AI before any custom model.
- Do not mix with legacy or previous systems.
